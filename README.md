# Quick Quiz

A modern, interactive quiz application that makes learning fun and engaging! Create and take quizzes with a beautiful glassmorphism design and instant feedback.

## ✨ Features

- **Easy Quiz Creation**: Generate quiz data using AI or input your own JSON
- **Instant Feedback**: See your answers right away with the instant answer option
- **Beautiful Design**: Modern glassmorphism UI that's easy on the eyes
- **Mobile Friendly**: Works great on all devices, from desktop to mobile
- **AI Integration**: Generate quiz content using popular AI models (ChatGPT, Claude, Gemini)

## 🚀 Getting Started

1. **Clone the repository**:

   ```bash
   git clone https://github.com/sudarshaana/quick-quiz.git
   ```

2. **Open the project**:
   - Simply open `index.html` in your favorite browser
   - No installation or setup required!

## 🎮 How to Use

### Creating a Quiz

1. **Using AI**:
   - Click "Generate Data"
   - Enter your topic and number of questions
   - Copy the generated prompt
   - Use it with your favorite AI model
   - Paste the generated JSON back into the quiz input

2. **Manual Input**:
   - Write or paste your quiz JSON directly into the input field
   - Format your JSON like this:

   ```json
   {
     "questions": [
       {
         "question": "What is the capital of France?",
         "options": ["London", "Berlin", "Paris", "Madrid"],
         "answer": "Paris"
       }
     ],
     "instantAnswer": false
   }
   ```

### Taking a Quiz

1. Click "Generate Quiz" to start
2. Answer questions by clicking on your choice
3. Navigate between questions using the arrow buttons
4. See your results at the end!
